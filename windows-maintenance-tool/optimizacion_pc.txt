=== RAM
Paso 1:
Monitor de recursos/Memoria -> comprobar memoria que se usa y la que está en espera
RAMMap/Empty/Empty Standby List -> liberar memoria y optimizar

Paso 2:
Configuración/Accesibilidad/Desactivar mostrar animaciones en Windows y transparencia

En W11: 
1. Start > Settings > Accessibility > Visual effects > Toggle Animation > off
2. Windows Key + R, type in SystemPropertiesPerformance.exe

Paso 3:
Task Manager/Inicio/Deshabilitar aplicaciones que no se usan (o tienen un gran impacto)

Paso 4:
Ajustar apariencia y rendimiento/Ajustar para obtener mejor rendimiento/Activar suavizar borde para fuentes (para que la letra no se vea fea)
